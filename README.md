# Personal notes

Ideas about how to improve professionally. These are working notes: a habit to build, a way of thinking that is easy to skip, something to be more deliberate about on the next real task.

Writing one down is useful when it names the practice. A realization that stays abstract does not change how the next bug or feature gets done.

## Adding a note

1. Copy [`templates/idea.md`](templates/idea.md) to `notes/YYYY-MM-DD-short-title.md`.
2. Write the realization, then the practice: what to do differently when the next change shows up.
3. Add a row to the index below.

Status is one of:

- **seed** — captured, not yet tried on a real task
- **practicing** — being used on purpose
- **habit** — showing up without a reminder
